# Code of Conduct

Vibe TV is a friendly, welcoming project. Everyone who takes part (in issues, pull requests,
discussions or anywhere else the project lives) is expected to:

- be respectful and patient, and assume good intent;
- give and take feedback about the work, not the person;
- welcome newcomers and questions of every level;
- keep it on topic, and keep private information private (yours and other people's).

Harassment, insults, discrimination, and sharing other people's personal details or logins are not
accepted. Maintainers may edit or remove contributions that break these rules and, if needed, block
someone from the project.

To report a problem, open an issue, or contact the maintainer through their GitHub profile if it
shouldn't be public.

This code is based on the spirit of the [Contributor Covenant](https://www.contributor-covenant.org/).
